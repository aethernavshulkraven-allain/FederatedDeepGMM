## Scientific Comparison

The old and new tuned Sine plots are scientifically consistent: they use the same FedGDA-D baseline artifacts and the same tuned FedOGDA-D A2-lite artifacts. Numeric curve metrics match to floating-point/CSV precision.

Summary for tuned Sine A2-lite:

- FedOGDA-D curve-MSE wins: 3/3 seeds.
- FedOGDA-D Test-MSE wins: 3/3 seeds.
- Mean curve MSE: FedGDA-D 0.0861068629 -> tuned FedOGDA-D 0.0800115346.
- Mean Test MSE at validation-selected checkpoint: FedGDA-D 0.0861068629 -> tuned FedOGDA-D 0.0800115346.

## Presentation Differences

- Existing A2-lite plot `a2_lite_sine_curve_all_seeds.png` shows all three seeds as separate stacked panels, which is best for audit/verification.
- Existing A2-lite plot `a2_lite_sine_curve_seed0.png` shows only seed 0.
- New plot `sine_a2_lite_all_seeds_mean.png` shows the mean curve across seeds, which is cleaner for a paper/slide summary.
- New plot `lowdim_deterministic_summary_2x2.png` combines Absolute, Step, Linear, and tuned Sine in one coauthor-facing figure.
- Existing plots use orange for FedGDA-D and blue for FedOGDA-D. New plots use blue dashed for FedGDA-D and red dash-dot for tuned FedOGDA-D.
- Existing plots are PNG only. New plots include both PNG and PDF.

## Recommendation

Use `experiments/sine_fedogda_tuning/plots/a2_lite_sine_curve_all_seeds.png` if the coauthor wants the original seed-by-seed tuned Sine figure.

Use `experiments/curve_fitting_plots/png/tuned_sine_a2_lite/sine_a2_lite_all_seeds_mean.png` or `experiments/curve_fitting_plots/png/coauthor_summary/lowdim_deterministic_summary_2x2.png` for compact paper-facing summary figures.

There is no evidence of a scientific mismatch between the older tuned Sine plots and our generated tuned Sine plots; the difference is presentation scope and styling.
