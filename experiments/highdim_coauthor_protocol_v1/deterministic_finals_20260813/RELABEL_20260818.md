# Relabel notice — 2026-08-18

The 108 runs in this directory (`deterministic_finals_20260813`) are **not**
discarded, overwritten, or superseded. They remain valid data under their
correct label:

> **Three-seed exploratory finals using configurations selected by seed-0,
> 150-round validation MSE.**

They are not, and should no longer be represented as, the confirmed output
of the adopted Rank/Confirm methodology (validation Ψ primary, 500-round
multi-seed). The runs were originally launched and reported as finals; this
relabel is a correction made after finding the protocol mismatch, not a
statement about original intent. That confirmation has not yet run — see
`../deterministic_screen_20260813/BOUNDARY_RULE_AMENDMENT_20260818.md` and
the adjudication/confirmation manifests prepared alongside it.

## Corrected figures

- **Actual GPU cost: 66.66 GPU-hours** (summed `runtime_seconds` across all
  108 `metrics.json` files, measured 2026-08-18). The 81.0 GPU-h figure
  quoted earlier was the pre-launch estimate from per-scenario cost
  extrapolation, not the measured figure — the estimate ran ~18% high,
  consistent with the same pattern seen on the original screen (measured
  15.5 GPU-h vs. 17.7 GPU-h estimated).
- **Accurate discrepancy statement:** the screen-stage Ψ rank-1 candidate
  differs from this directory's frozen MSE-selected configuration in
  **11 of 12 cells**. This is not evidence that 11 configurations are
  wrong:
  - For **8 cells** (`femnist_z`, `femnist_xz`, `cifar10_z`, `cifar10_xz` ×
    both methods), Ψ separates candidates by a large seed-0 observed gap,
    pending multi-seed confirmation — the gaps look meaningful, but noise
    has not yet been measured across seeds. This is a genuine protocol
    discrepancy between how these configs were actually selected and how
    the adopted plan specifies they should have been selected.
  - For **4 cells** (`femnist_x`, `cifar10_x` × both methods), every
    candidate's Ψ value sits within noise of zero. Ψ has not demonstrated
    that it can distinguish candidates in these scenarios at all — see the
    diagnostic in `PSI_X_SCENARIO_DIAGNOSTIC_20260818.md`. This is not
    evidence the MSE-selected configs are wrong either; it's evidence Ψ may
    not be a usable selection signal for this scenario architecture.

## What happens to this data

Kept as-is, permanently, as the exploratory/pilot table. If the pending
Rank/Confirm adjudication (Ψ vs. MSE, 500-round, 3-seed, per cell) confirms
a different winner for a given cell, only that cell's finals get rerun with
the confirmed config — this directory's existing runs for unchanged cells
are reused, not repeated.
